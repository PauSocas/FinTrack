# FinTrack 

App de finanzas personales desarrollada en Android nativo con Kotlin.

## Funcionalidades
- Registro de ingresos y gastos por categoría
- Dashboard con balance mensual y gráfico interactivo
- Desglose de gastos al pulsar cada categoría
- Cuestionario de perfil inversor
- Arquitectura MVVM con Room, LiveData y Coroutines

## Tecnologías
Kotlin | MVVM | Room DB | Navigation Component | MPAndroidChart | Material3 |  ViewBinding | Coroutines | Flow
